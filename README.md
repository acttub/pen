# pen

acttub 디자인 .pen 원본(Pencil, https://pen.dev).

| 파일 | 무엇 |
|---|---|
| `acttub 디자인.pen` | 작업 정본. 캔버스를 **앱 · 웹앱 · 웹** 세 구역으로 나눠 한 문서에 둔다 (구 `RN앱 반영.pen`) |

`목업v2.pen`(웹앱 프론트 정본, 프레임 53개)은 이 저장소에서 빠졌다. 커밋
`62eaa01`에 남아 있어 필요하면 거기서 꺼낸다.

## 캔버스 구역

캔버스는 왼쪽부터 세 구역으로 나뉘고, 사이에 세로 구분선이 있다. 구역 제목은
모두 y −320 줄에 맞춰 두었다.

| 구역 | 무엇 | x 범위 |
|---|---|---|
| 앱 | `A*` RN 앱 화면 · `WF*` 와이어프레임 탭 · 상대역 리딩 흐름 메모 | −9190 ~ −4860 |
| 웹앱 | `M*` → `M-R` → `W*` 모바일 웹 · 약관·M-R 메모 | −3300 ~ 940 |
| 웹 | `D*` 데스크톱 웹 | 1200 ~ 15270 |

재사용 컴포넌트(브라우저 상단 · 대학 카드 · 탭 바)는 웹앱 구역 위쪽 줄(y −1680 ~ −940)에 모아 둔다.
새 화면은 해당 구역 안에서 아래로 늘리고, 구역을 넘기지 않는다.

## 프레임 이름 규칙

한 문서에 세 층이 섞여 있어 접두사로 구분한다.

| 접두사 | 무엇 | 폭 |
|---|---|---|
| `D*` | 데스크톱 웹 | 1440 |
| `M*` | 모바일 웹 (기존 정본) | 390×844 |
| `W*` | 모바일 웹 — **앱 디자인 적용** | 390×844 |
| `A*` | RN 앱 화면 미러 | 390×844 |
| 이름만 | 재사용 컴포넌트 (탭 바 · 대학 카드 · 브라우저 상단) | — |

`W*` 는 `M*` 와 번호가 1:1로 대응한다 (`M6.1-R` ↔ `W6.1-R`). 대응하는 `M` 이
없는 웹 전용 화면은 `WC` 를 쓴다.

## W 프레임을 만드는 규칙

**디자인은 RN 앱을 따르고, 플로우는 웹을 따른다.**

- 원본은 앱에 맞춰 고친 `-R` 프레임에서 복사한다. 구세대 `M6.1`·`M6.3` 같은
  프레임에서 뜨면 옛 웹 디자인이 그대로 붙는다
- 상단 `←` 를 **`☰`** 로 바꾼다. 데스크톱 세션 바(280)가 접힌 것이고, 열린
  상태가 `W8 세션 목록 드로어` 다
- **앱 하단 탭 바는 지운다.** 웹 내비게이션은 사이드바이고 그게 드로어가 된다
- 브라우저 주소창(`브라우저 상단` 컴포넌트)을 맨 위에 얹는다
- `390×844` 고정 + `clip: true`. 넘치는 내용은 웹에서 스크롤되는 영역이다

## Pencil 작업 시 주의

- **MCP 의 `filePath` 인자는 무시되고 활성 문서만 편집된다.** 작업 전에 Pencil
  에서 이 파일을 열어 활성 창으로 만들 것. 안 그러면 다른 문서에 편집이 쌓인다
- **루트에 `Insert` 로 새 프레임을 만들면 자식이 아래로 밀린다.** 기존 프레임을
  `Copy` 해서 시작하면 정상이다
- 워드마크가 볼트 경로(`../Soma/planning/...`)를 참조해 이 저장소에서는 깨진다
- `.pen` 은 Pencil 앱으로만 연다(암호화 바이너리, git diff 무의미)
